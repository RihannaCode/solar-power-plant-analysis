# Solar Power Plant Data Analysis ☀️

This is a small Python project I worked on to practice NumPy using real solar power plant data.

### What I did
- Analyzed AC and DC power data.
- Compared the performance of 22 inverters.
- Calculated daily energy production.
- Found days with lower energy production.
- Created two graphs using Matplotlib.

### Tools
- Python
- NumPy
- Matplotlib

### Dataset
Solar Power Generation Data — Kaggle  
File: `Plant_1_Generation_Data.csv`

### What I learned
This project helped me practice working with real CSV data, NumPy arrays, loops, conditions, and data visualization.
